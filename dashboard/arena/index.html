Leyendo tarifas y volumen…

Costos desde el cambio de modelo

Comisión = importe ejecutado × tarifa. Las compras y ventas cuentan para el volumen móvil de 30 días; la operación actual solo puede cambiar el escalón de las siguientes. Las carteras simulan cuentas independientes. Exactamente en un umbral se conserva la tarifa anterior.

La comparación usa las mismas cantidades y precios registrados. «Todo maker» es un costo hipotético: una orden que agrega liquidez puede no ejecutarse. No mide una ganancia alternativa. Las comisiones históricas siguen intactas y ya están descontadas del patrimonio.

Fuente: tabla pública de Bitso · mercados USD, verificada el 5-oct-2026. Tarifas simuladas; tu nivel de cuenta privado no está verificado. No se generan operaciones para alcanzar descuentos.
